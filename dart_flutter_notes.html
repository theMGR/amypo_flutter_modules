Dart & Flutter Basics — Quick Reference

Core syntax, control flow, OOP, async, and the most common Flutter widgets with minimal examples.

A companion runnable file, common_widgets_demo.dart, demonstrates all the widgets below together in a single working app (Gallery + Tabs/Pages screens).

Dart Language Basics

Variables & Types DART

A variable is a named box that holds a value. The type tells Dart what kind of value it can hold.

int age = 25;
double height = 5.9;
String name = "John";
bool isOn = true;
var x = 10;      // type inferred
dynamic y = 10;  // type can change
final z = 5;     // set once
const pi = 3.14; // compile-time constant

Use final for runtime constants, const for compile-time constants.

Collections DART

Collections group multiple values together. List = ordered items, Set = unique items, Map = key-value pairs.

List<int> nums = [1, 2, 3];
Set<String> unique = {"a", "b"};
Map<String, int> ages = {
  "Tom": 20,
  "Sam": 25,
};

nums.add(4);
ages["Tom"];        // 20
nums.where((n) => n > 1);
nums.map((n) => n * 2).toList();

Control Flow DART

Control flow decides which code runs, and how many times, based on conditions.

if (age > 18) {
  print("Adult");
} else if (age == 18) {
  print("Just turned");
} else {
  print("Minor");
}

for (int i = 0; i < 5; i++) { }
for (var item in nums) { }
while (age < 30) { age++; }

switch (age) {
  case 18:
    print("18");
    break;
  default:
    print("other");
}

Functions DART

A function is a reusable block of code that performs a task and can accept inputs and return a value.

int add(int a, int b) {
  return a + b;
}

int addArrow(int a, int b) => a + b;

// optional named params
void greet({String name = "Guest"}) {
  print("Hi $name");
}
greet(name: "Sam");

// optional positional params
void log([String? msg]) {
  print(msg ?? "no message");
}

Null Safety DART

Null safety means a variable can only be empty (null) if you explicitly allow it, preventing crashes.

String? nickname;         // nullable
String name = nickname ?? "Anon"; // default if null
nickname?.length;         // safe call
int len = nickname!.length; // force unwrap (risky)

Dart's sound null safety prevents null reference errors at compile time.

Classes & OOP DART

A class is a blueprint for creating objects that bundle data (fields) and behavior (methods) together.

class Person {
  String name;
  int age;

  Person(this.name, this.age);

  void greet() => print("Hi, I'm $name");
}

class Student extends Person {
  String school;
  Student(String name, int age, this.school)
      : super(name, age);
}

var s = Student("Sam", 20, "MIT");
s.greet();

Async Programming DART

Async code lets slow tasks (like network calls) run in the background without freezing the app.

Future<String> fetchData() async {
  await Future.delayed(Duration(seconds: 2));
  return "Data loaded";
}

void main() async {
  print("Start");
  String result = await fetchData();
  print(result);
}

async marks a function as asynchronous; await pauses until the Future resolves.

Exception Handling DART

Exception handling catches errors at runtime so the app can respond gracefully instead of crashing.

try {
  int result = 10 ~/ 0;
} catch (e) {
  print("Error: $e");
} finally {
  print("Always runs");
}

throw Exception("Custom error");
Flutter Basics

App Entry Point FLUTTER

Every Flutter app starts by running the main() function, which launches the root widget on screen.

import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Demo',
      home: HomeScreen(),
    );
  }
}

Stateless vs Stateful FLUTTER

Stateless widgets never change once built. Stateful widgets can redraw themselves when their data changes.

// No internal state, immutable
class Greeting extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Text("Hello");
  }
}

// Has mutable state
class Counter extends StatefulWidget {
  @override
  State<Counter> createState() => _CounterState();
}

class _CounterState extends State<Counter> {
  int count = 0;

  void increment() {
    setState(() => count++);
  }

  @override
  Widget build(BuildContext context) {
    return Text("$count");
  }
}

Widget Tree Concept FLUTTER

Everything on screen in Flutter is a widget — text, layout, padding, buttons all nest together to form a tree.

The build() method describes what the UI looks like, and re-runs whenever the widget's state changes.

Common Widgets

Text & Icon

Text displays a string on screen; Icon displays a small built-in graphic symbol.

Text(
  "Hello Flutter",
  style: TextStyle(
    fontSize: 18,
    fontWeight: FontWeight.bold,
    color: Colors.blue,
  ),
)

Icon(Icons.favorite, color: Colors.red, size: 30)

Container

A box widget used to hold, size, pad, and decorate another widget (like a div in HTML).

Container(
  width: 100,
  height: 100,
  padding: EdgeInsets.all(8),
  margin: EdgeInsets.symmetric(horizontal: 12),
  decoration: BoxDecoration(
    color: Colors.teal,
    borderRadius: BorderRadius.circular(12),
  ),
  child: Text("Box"),
)

Row & Column

Row arranges widgets side by side horizontally; Column stacks widgets vertically.

Row(
  mainAxisAlignment: MainAxisAlignment.spaceBetween,
  children: [
    Icon(Icons.star),
    Icon(Icons.star),
  ],
)

Column(
  crossAxisAlignment: CrossAxisAlignment.start,
  children: [
    Text("Line 1"),
    Text("Line 2"),
  ],
)

Stack

Stack layers widgets on top of one another, like sheets of paper piled together.

Stack(
  alignment: Alignment.center,
  children: [
    Container(color: Colors.grey, width: 100, height: 100),
    Positioned(
      bottom: 8,
      right: 8,
      child: Icon(Icons.edit),
    ),
  ],
)

Overlays widgets on top of each other, useful for badges or floating labels.

ListView

A scrollable widget that displays a list of items, one after another.

// Fixed short list
ListView(
  children: [Text("A"), Text("B")],
)

// Large/dynamic list (lazy loaded)
ListView.builder(
  itemCount: items.length,
  itemBuilder: (context, index) {
    return ListTile(title: Text(items[index]));
  },
)

// List with dividers between items
ListView.separated(
  itemCount: items.length,
  separatorBuilder: (context, index) => Divider(),
  itemBuilder: (context, index) => Text(items[index]),
)

// Horizontal scrolling list
ListView(
  scrollDirection: Axis.horizontal,
  children: [Container(width: 80), Container(width: 80)],
)

.builder only renders items on screen (lazy) — best for long lists.

DropdownButton

A tappable field that shows a menu of options and lets the user pick one.

String? selected = "One";

DropdownButton<String>(
  value: selected,
  items: ["One", "Two", "Three"]
      .map((v) => DropdownMenuItem(
            value: v,
            child: Text(v),
          ))
      .toList(),
  onChanged: (value) {
    setState(() => selected = value);
  },
)

Wrap in DropdownButtonFormField for a labeled, form-style dropdown.

Radio

A round button used to pick exactly one option from a group.

int groupValue = 1;

Radio<int>(
  value: 1,
  groupValue: groupValue,
  onChanged: (val) => setState(() => groupValue = val!),
)

Slider

A draggable bar for choosing a numeric value within a range.

double value = 20;

Slider(
  value: value,
  min: 0,
  max: 100,
  divisions: 5,
  label: value.round().toString(),
  onChanged: (val) => setState(() => value = val),
)

Form & TextFormField

Form groups input fields together so they can all be validated and saved at once.

final formKey = GlobalKey<FormState>();

Form(
  key: formKey,
  child: TextFormField(
    decoration: InputDecoration(labelText: "Email"),
    validator: (value) {
      if (value == null || value.isEmpty) return "Required";
      return null;
    },
  ),
)

// check validity
if (formKey.currentState!.validate()) { }

GestureDetector & InkWell

Both detect taps, drags, and other touches on a widget. InkWell also shows a ripple effect.

GestureDetector(
  onTap: () => print("Tapped"),
  child: Text("Tap me"),
)

InkWell(
  onTap: () => print("Tapped with ripple"),
  child: Padding(
    padding: EdgeInsets.all(8),
    child: Text("Tap me"),
  ),
)

Expanded & Flexible

Used inside Row/Column to control how much space a child takes up relative to others.

Row(
  children: [
    Expanded(
      flex: 2,
      child: Container(color: Colors.red),
    ),
    Expanded(
      flex: 1,
      child: Container(color: Colors.blue),
    ),
  ],
)

Expanded forces the child to fill the space; Flexible lets it shrink to fit.

Wrap

Lays out children in a row, automatically wrapping to a new line when space runs out.

Wrap(
  spacing: 8,
  runSpacing: 8,
  children: [
    Chip(label: Text("Dart")),
    Chip(label: Text("Flutter")),
    Chip(label: Text("Mobile")),

)

Chip

A small rounded label, often used for tags, filters, or selections.

Chip(
  label: Text("Flutter"),
  avatar: Icon(Icons.tag),
  onDeleted: () => print("Removed"),

SingleChildScrollView

Makes a single widget (like a tall Column) scrollable when it overflows the screen.

SingleChildScrollView(
  child: Column(
    children: [ /* many widgets */ ],
  ),
)

SafeArea

Keeps content away from notches, status bars, and system UI cutouts.

SafeArea(
  child: Text("Won't overlap the notch"),
)

Drawer

A slide-out side menu, usually opened from the AppBar's hamburger icon.

Scaffold(

BottomNavigationBar

A bar of tappable icons at the bottom of the screen for switching between main sections.

Spinners or bars that show the app is loading or working on something.

CircularProgressIndicator()

StreamBuilder

Like FutureBuilder, but rebuilds the UI repeatedly as new values arrive over time.

StreamBuilder<int>(
  stream: counterStream,
  builder: (context, snapshot) {
    if (!snapshot.hasData) return CircularProgressIndicator();
    return Text("Count: ${snapshot.data}");

)

Buttons

Tappable widgets that trigger an action when pressed.

TextField

An input box that lets the user type and edit text.

final nameController = TextEditingController();

TextField(
  controller: nameController,
  decoration: InputDecoration(
    labelText: "Enter name",
    border: OutlineInputBorder(),
  ),
  onChanged: (value) => print(value),
)

// read the current text anytime
print(nameController.text);

// set text programmatically
nameController.text = "Sam";

// clear the field
nameController.clear();

// always dispose in a StatefulWidget
@override
void dispose() {
  nameController.dispose();
  super.dispose();
}

Use controller when you need to read, set, or clear the text from code (not just onChanged).

Checkbox & Switch

Checkbox is a tickable box for yes/no choices; Switch is a sliding on/off toggle.

Checkbox(

)

Switch(

FutureBuilder

A widget that automatically rebuilds itself based on the result of a Future (like a loading spinner then data).

FutureBuilder<String>(
  future: fetchData(),
  builder: (context, snapshot) {
    if (snapshot.connectionState == ConnectionState.waiting) {
      return CircularProgressIndicator();
    } else if (snapshot.hasError) {
      return Text("Error: ${snapshot.error}");
    } else {
      return Text(snapshot.data!);
    }
  },
)

Rebuilds UI based on a Future's state — perfect for API calls.

Controllers & Keys FLUTTER

Controllers let code talk to a widget directly (read/change its value); Keys let Flutter tell widgets apart.

TextEditingController

final controller = TextEditingController();
TextField(controller: controller);
controller.text;      // read
controller.clear();   // clear

GlobalKey<FormState>

final formKey = GlobalKey<FormState>();
Form(key: formKey, child: /* fields */);
formKey.currentState!.validate();
formKey.currentState!.save();

ScrollController

final scrollController = ScrollController();
ListView(controller: scrollController);
scrollController.animateTo(
  0,
  duration: Duration(milliseconds: 300),
  curve: Curves.easeOut,
);

PageController

final pageController = PageController();
PageView(controller: pageController);
pageController.nextPage(
  duration: Duration(milliseconds: 300),
  curve: Curves.ease,
);

TabController

// needs "with SingleTickerProviderStateMixin" on the State class
late TabController tabController =
    TabController(length: 2, vsync: this);
TabBar(controller: tabController);

AnimationController

// needs "with SingleTickerProviderStateMixin"
late AnimationController animController = AnimationController(
  duration: Duration(seconds: 1),
  vsync: this,
);
animController.forward(); // start animation

GlobalKey (general)

final widgetKey = GlobalKey();
Container(key: widgetKey);
// access the widget's state/size/position from code

Rule of thumb: any controller created in a StatefulWidget must be disposed in dispose() to avoid memory leaks.

@override
void dispose() {
  controller.dispose();
  scrollController.dispose();
  pageController.dispose();
  tabController.dispose();
  animController.dispose();
  super.dispose();
}
Run & Build Commands

Run the App CLI

Launches the app in debug mode on a connected device, emulator, or simulator.

flutter run

# choose a specific device
flutter devices
flutter run -d chrome
flutter run -d emulator-5554

# hot reload: press "r" in terminal while running
# hot restart: press "R"
# quit: press "q"

Build APK (Android) CLI

Produces a standalone Android install file (.apk), useful for direct install/testing.

flutter build apk

# smaller, split per CPU architecture (recommended for size)
flutter build apk --split-per-abi

# release mode, specific target
flutter build apk --release

# output location:
# build/app/outputs/flutter-apk/app-release.apk

Build App Bundle / AAB CLI

Produces the .aab format required for publishing to the Google Play Store.

flutter build appbundle

# release build (default)
flutter build appbundle --release

# output location:
# build/app/outputs/bundle/release/app-release.aab

Play Store requires AAB, not APK, for new app submissions.

Build for Web CLI

Compiles the app into HTML/JS/CSS that can be hosted on any web server.

flutter build web

# release build with a specific renderer
flutter build web --release --web-renderer canvaskit

# output location:
# build/web/  (deploy this folder to hosting)

# quick local preview
flutter run -d chrome

Build for iOS CLI

Compiles the app for iOS devices; requires a Mac with Xcode installed.

flutter build ios

# build an .ipa for distribution (App Store / TestFlight)
flutter build ipa

# output location:
# build/ios/iphoneos/
# build/ios/ipa/ (for .ipa)

After building, open the iOS project in Xcode to archive and upload, or use flutter build ipa directly.

Build for Desktop CLI

Compiles the app into a native desktop application for Windows, macOS, or Linux.

flutter build windows
flutter build macos
flutter build linux

# enable desktop support if not already
flutter config --enable-windows-desktop
flutter config --enable-macos-desktop
flutter config --enable-linux-desktop

Useful Project Commands CLI

Everyday commands for setting up, cleaning, and diagnosing a Flutter project.

flutter create my_app        # start a new project
flutter pub get              # install dependencies
flutter pub upgrade          # update dependencies
flutter clean                # clear build cache
flutter doctor                # check setup/environment issues
flutter analyze              # static analysis / lint
flutter test                 # run unit/widget tests
flutter --version            # check installed Flutter version

Build Modes CLI

Flutter builds run in one of three modes depending on the flag used.

  • --debug (default with flutter run) — hot reload, assertions on, slower, for development.
  • --profile — near-release performance, keeps some tooling for profiling.
  • --release — optimized, smaller, no debug banner, for shipping to users.
flutter run --release
flutter build apk --release
flutter build web --release
